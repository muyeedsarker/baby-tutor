# Baby Tutor — Design Lock

This repository should use the supplied Baby Tutor MASTER version as the visual source of truth.

## Non-negotiable rules
1. Do not redesign, restyle, regenerate, or replace the existing UI.
2. Do not remove, reorder, or rewrite existing CSS/JS unless the requested change specifically requires it.
3. Preserve the Premium HD 3D/candy visual style, spacing, typography, colors, shadows, rounded cards, animations, navigation, and responsive behavior.
4. Use the existing image assets. Do not create substitute images when an existing asset is available.
5. Keep index.html as the single entry point.
6. Keep asset paths relative to the project root so the project works on GitHub Pages and locally.
7. Make only the smallest change necessary for a requested feature or bug fix.
8. Before changing a UI component, inspect the existing CSS and JavaScript controlling it.
9. Never add a second competing theme or a new global reset without an explicit request.
10. Never replace the whole index.html with a newly generated version.

## Preview rule
Different AI/code previews may render fonts, viewport sizes, and external resources differently. Treat the approved Master files as authoritative; do not fix visual differences by inventing a new design.
